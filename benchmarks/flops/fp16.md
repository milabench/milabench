## Overview

**Benchmark:** fp16
**dtype:** `torch.float16`
**Matrix size:** 8192 x 8192
**Kernel:** `torch.mm`

### Config (config/synthetic.yaml)

```yaml
fp16:
  inherits: _flops
  argv:
    --number: 30
    --repeat: 90
    --m: 8192
    --n: 8192
    --dtype: fp16
```

### Notes

- Standard half-precision matmul via tensor cores.
- More prone to overflow/underflow than bf16 due to narrow exponent range.
- Uses pre-allocated `out` tensor to avoid allocation in timing loop.

### Run standalone

```bash
python main.py --number 30 --repeat 90 --m 8192 --n 8192 --dtype fp16
```
