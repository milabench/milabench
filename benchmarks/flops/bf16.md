## Overview

**Benchmark:** bf16
**dtype:** `torch.bfloat16`
**Matrix size:** 8192 x 8192
**Kernel:** `torch.mm`

### Config (config/synthetic.yaml)

```yaml
bf16:
  inherits: _flops
  argv:
    --m: 8192
    --n: 8192
    --dtype: bf16
```

### Notes

- Uses default `--number 10` and `--repeat 90` from `_flops` base (unlike fp8/fp16 which override to 30).
- bfloat16 has the same exponent range as fp32 - rarely overflows in practice.
- Preferred training dtype on Ampere+; this benchmark validates that tensor-core throughput matches spec.

### Run standalone

```bash
python main.py --number 10 --repeat 90 --m 8192 --n 8192 --dtype bf16
```
