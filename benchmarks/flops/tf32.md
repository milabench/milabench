## Overview

**Benchmark:** tf32
**dtype:** `torch.float32` with TF32 tensor cores enabled
**Matrix size:** 8192 x 8192
**Kernel:** `torch.mm`

### Config (config/synthetic.yaml)

```yaml
tf32:
  inherits: _flops
  argv:
    --m: 8192
    --n: 8192
    --dtype: fp32
    --tf32: true
```

### Notes

- Passes `--dtype fp32` but sets `--tf32` flag which calls `accelerator.set_enable_tf32(True)`.
- TF32 rounds fp32 inputs to 10-bit mantissa before using tensor cores - ~8x throughput vs pure fp32.
- Should show significantly higher TFLOPS than `fp32` on Ampere+ GPUs.
- Identical memory footprint to fp32 (data stays 32-bit), only compute precision changes.

### Run standalone

```bash
python main.py --number 10 --repeat 90 --m 8192 --n 8192 --dtype fp32 --tf32
```
