## Overview

**Benchmark:** fp32
**dtype:** `torch.float32` (TF32 disabled)
**Matrix size:** 8192 x 8192
**Kernel:** `torch.mm`

### Config (config/synthetic.yaml)

```yaml
fp32:
  inherits: _flops
  argv:
    --m: 8192
    --n: 8192
    --dtype: fp32
```

### Notes

- Full IEEE754 single precision - no tensor core truncation.
- Baseline for comparing TF32/bf16/fp16 speedups.
- Expect ~1/8 the throughput of tf32 on Ampere+ since CUDA cores are used instead of tensor cores.
- `--tf32` flag is absent, so `set_enable_tf32(False)` is the default.

### Run standalone

```bash
python main.py --number 10 --repeat 90 --m 8192 --n 8192 --dtype fp32
```
