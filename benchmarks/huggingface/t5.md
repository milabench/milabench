## Overview

## Config

- **Model**: T5 via `AutoModelForSeq2SeqLM.from_config()`, random weights
- **Batch size**: 16
- **Precision**: tf32-fp16 (TF32 matmul + autocast fp16, GradScaler enabled)

## Data

Synthetic: random `input_ids` + `labels` of shape `(train_length,)` with values
in `[0, vocab_size)`. Pre-generated in RAM, served round-robin. Uses the
`AutoModelForSeq2SeqLM` category path in `synth.py`.

## Notes

Smaller batch size than BERT (16 vs 32) due to the encoder-decoder architecture
requiring more memory per sample.

## Quirks

- Loss computed internally by the HF model when `labels` are passed.
- fp16 autocast falls back to bf16 on non-CUDA backends.
- `accelerator.optimize()` is called WITHOUT explicit dtype -- passing dtype
  causes Reformer to fail, so it was removed globally for all huggingface models.
