\paragraph{Stragglers.} With FSDP, all ranks wait for the slowest one, so per-rank step times are identical
(measured: 24 ranks within 0.2\,ms) and cannot identify a slow GPU. The slow GPU is instead the one that
\emph{waits least}: it is busy for a larger share of each step while the others idle at the collective
(\cref{fig:stragglers}, top). The measure is the GPU's duty cycle over each sampling interval, from the
utilization samples the driver buffers; where the node runs a DCGM exporter, tensor-pipe occupancy replaces
it and ranks equally busy GPUs more sharply. A duty cycle separates a GPU that waits from one that does
not, but it is not a profiling counter. The second, independent cause
is the host: a node whose CPU busy-core clock falls holds back every rank on it (\cref{fig:stragglers},
bottom; measured before the window on one node, 3{,}700 to 2{,}560\,MHz for
\(-25\,\%\) throughput).
