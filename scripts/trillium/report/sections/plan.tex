\section{What ran, and what is left}
\label{app:plan}

The design planned for 52 nodes; \cref{sec:machine} says why the top is about 39--43. \Cref{tab:progress} counts planned points: a configuration at a node count, repetitions not counted. Failed: the run failed and the failure answers the question, so the point counts as done (for example, out of memory). Points that need 50 or more nodes wait for the 200\,W caps to clear, and count apart. The plan is the design's, as the launchers carry it, changed as results came in: 48k tokens per GPU with selective recompute was skipped, for memory, and \texttt{pp10-ep8} and \texttt{pp25-ep8} were added to fit 40 and 50 nodes. The network tests stopped at 25 nodes, the job limit then, so D4 did not run; the plan takes D2--D4 to 52 nodes as the design has it, with a step at 39, the largest clean set today.
